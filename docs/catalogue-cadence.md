# Catalogue Cadence — les 1324 noms d'exercices

Les noms **exacts** du catalogue qu'embarque Cadence Tabata. Reprends-les **mot pour mot** :
c'est l'orthographe qui décide si une démonstration animée s'affiche pendant l'effort. Un
nom hors catalogue reste utilisable — la séance se déroule, simplement sans démonstration.

- Le catalogue est **en anglais**. « pompes » n'y existe pas, « push-up » oui.
- Les sept groupes regroupent les dix zones du catalogue : **Bras** = bras + avant-bras,
  **Torse** = pectoraux + épaules, **Jambes** = cuisses + mollets. **Cardio** et **Cou**
  n'entrent dans aucun des cinq groupes usuels et sont donc nommés à part.
- Sous chaque groupe, **poids du corps d'abord** — c'est ce qu'une séance tabata emploie le
  plus souvent —, puis le reste rangé par matériel.

Source : github.com/hasaneyldrm/exercises-dataset (données sous licence MIT).
